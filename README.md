# ⚖️ ТрудПраво (TrudPravo)

> **Интеллектуальный юридический AI-ассистент по Трудовому кодексу Республики Казахстан**  
> Проект разработан на базе гибридного RAG-пайплайна (ChromaDB + BM25) и LLM (Groq Cloud).

---

## 📌 О проекте

**ТрудПраво** — веб-приложение для получения юридических консультаций по трудовому законодательству Казахстана. Пользователь задает вопрос на обычном языке, система находит точные статьи Трудового кодекса РК (от 23.11.2015 № 414-V с актуальными изменениями) и формирует структурированный ответ со ссылками на первоисточник вида `[S1]`, `[S2]`.

### Ключевые возможности:
- **100% обоснованность (Grounding):** ответы формируются строго по статьям ТК РК без внешних галлюцинаций.
- **Гибридный поиск (Hybrid Retrieval):** комбинация семантического поиска (векторы) и поиска по ключевым словам и номерам статей (BM25).
- **Прямые цитаты:** каждый факт подкрепляется номером статьи и пункта кодекса.
- **Сохранение истории:** все сессии и переписка сохраняются в локальной базе данных SQLite.
- **Интерактивный UI:** готовый веб-интерфейс с темами-подсказками, анимацией загрузки и страницами профиля/авторизации.

```

       │
       ▼  HTTP / JSON

       │

       │     └── Сохранение сессий и сообщений
       │

                   │
                   ▼
       Гибридный Retriever (backend/rag/retriever.py)
        ├── 1. Точные ключевые слова/статьи: BM25 (rank_bm25)
        ├── 2. Векторный семантический поиск: ChromaDB + sentence-transformers
        └── 3. Слияние рангов: Reciprocal Rank Fusion (RRF)
                   │
                   ▼
             Топ-5 фрагментов ТК РК с breadcrumb-разметкой
                   │
                   ▼
          Groq Cloud LLM (openai/gpt-oss-120b)
                   │
                   ▼
      Ответ пользователю с цитатами [S1] + бейджи статей
```

## ⚙️ Установка и запуск

### 1. Требования
* Python 3.10 или выше (протестировано на Python 3.13)
* Доступ в интернет (для обращения к бесплатному Groq Cloud API)

### 2. Клонирование / переход в директорию
```bash
cd C:\Users\w2\Desktop\itprod
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Настройка `.env`
Файл `.env` уже создан в корне проекта и содержит рабочий ключ Groq API:
```env
GROQ_API_KEY=gsk_...
GROQ_BASE_URL=https://api.groq.com/openai/v1
GROQ_MODEL=openai/gpt-oss-120b
SECRET_KEY=change-me-to-random-string-in-production
```

### 5. Запуск веб-сервера
Запустите сервер FastAPI одной командой:
```bash
python -m uvicorn backend.main:app --reload --host 127.0.0.1 --port 8000
```

После старта перейдите в браузере по адресу:
👉 **[http://localhost:8000](http://localhost:8000)**

## 🔌 API Эндпоинты

### `POST /api/chat`
Основной эндпоинт отправки вопроса.
* **Тело запроса:**
  ```json
  {
    "message": "Какой максимальный испытательный срок при приеме на работу?",
    "session_id": null
  }
  ```
* **Ответ сервера:**
  ```json
  {
    "session_id": "67127aec39254d3b",
    "answer": "Согласно Трудовому кодексу Республики Казахстан, испытательный срок не может превышать три месяца... [S1].",
    "citations": [
      {
        "source_id": "S1",
        "breadcrumb": "ОСОБЕННАЯ ЧАСТЬ · Раздел 2. ТРУДОВЫЕ ОТНОШЕНИЯ · Глава 4 · Статья 36 · Пункт 2",
        "article_number": "36",
        "point_number": "2"
      }
    ]
  }
  ```

### `GET /api/chat/{session_id}/messages`
Возвращает полную историю переписки по указанной сессии с прикрепленными цитатами.

### `GET /api/sessions`
Список всех сохраненных диалогов для сайдбара.

### `GET /health`
Проверка состояния сервера и готовности RAG-компонентов.

## 🗄 Работа с базой данных через DBeaver

Все диалоги и сообщения автоматически сохраняются в SQLite:
* **Файл БД:** `C:\Users\w2\Desktop\itprod\data\trudpravo.db`

### Как открыть в DBeaver:
1. Откройте **DBeaver** → Нажмите **Новое соединение** (New Connection).
2. Выберите тип базы: **SQLite**.
3. В поле **Path (Путь к файлу базы данных)** укажите:
   `C:\Users\w2\Desktop\itprod\data\trudpravo.db`
4. Нажмите **Тест соединения** → **Готово**.
5. Таблицы:
   * `sessions` — список диалогов (`id`, `title`, `created_at`, `updated_at`).
   * `messages` — сообщения (`id`, `session_id`, `from_ai`, `content`, `meta_info` с JSON-цитатами).
